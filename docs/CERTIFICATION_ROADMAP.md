# 證照與法規路徑規劃（Certification Roadmap）

> **⚠️ 重要聲明**  
> 本文件為**概念研究與法規盤點階段**之參考架構，**不代表已取得任何認證、型式審驗或政府核准**。  
> 所有證照申請與法規合規作業，須待正式合作契約、IP 歸屬與商業條件確認後，由各市場主管機關依法審查辦理。

---

## 1. 總體原則

本專案之 AI Co-Pilot 定位為 **「輔助／資訊／提醒層」**，初期不直接控制方向盤、油門、煞車。  
惟未來若涉及量產車搭載、OTA 更新或特定功能，仍須依各國法規完成相應認證。

---

## 2. 中國市場（People's Republic of China）

| 類別 | 可能適用之法規／標準 | 現階段狀態 |
| :--- | :--- | :--- |
| **產品准入** | 工信部《道路機動車輛生產企業及產品准入許可》 | 待評估 |
| **智能網聯汽車** | 《關於加強智能網聯汽車產品准入、召回及軟體線上升級管理的通知》 | 待評估 |
| **功能安全** | GB/T 34590（對應 ISO 26262） | 待評估 |
| **網路安全** | GB/T 40861、ISO 21434 對應要求 | 待評估 |
| **數據安全** | 《汽車數據安全管理若干規定（試行）》 | 待評估 |
| **個人信息保護** | 《個人信息保護法》（PIPL） | 待評估 |
| **AI 演算法** | 《互聯網信息服務算法推薦管理規定》／生成式 AI 備案 | 待評估 |
| **OTA 升級** | 工信部 OTA 備案要求 | 待評估 |
| **電磁相容（EMC）** | GB 34660 等 | 待評估 |

> 中國市場目前對車載 AI 與數據出境審查趨嚴，未來若涉及數據傳輸至境外，須另行評估安全評估申報。

## 3. 美國市場（United States）

| 類別 | 可能適用之法規／標準 | 現階段狀態 |
| :--- | :--- | :--- |
| **聯邦機動車安全標準** | FMVSS（Federal Motor Vehicle Safety Standards） | 待評估 |
| **自動駕駛／輔助系統** | NHTSA 指導文件與自願性指引 | 待評估 |
| **功能安全** | ISO 26262（國際標準，美國車廠普遍採用） | 待評估 |
| **網路安全** | ISO 21434 ／ NHTSA 網路安全最佳實踐 | 待評估 |
| **州級法規** | 各州（如加州）對 AI 輔助駕駛之特定要求 | 待評估 |
| **出口管制** | EAR（Export Administration Regulations） | 待評估 |
| **數據隱私** | CCPA／CPRA 及其他州級隱私法 | 待評估 |

> 美國市場涉及「軟體定義車輛」及「OTA 更新」之監管動態，須持續關注 NHTSA 與各州立法進展。

## 4. 台灣市場（Taiwan）

| 類別 | 可能適用之法規／標準 | 現階段狀態 |
| :--- | :--- | :--- |
| **車輛型式安全審驗** | 交通部「車輛型式安全審驗管理辦法」 | 待評估 |
| **功能安全** | 參考 ISO 26262 之國家標準調和進度 | 待評估 |
| **個資保護** | 《個人資料保護法》 | 待評估 |
| **資通安全** | 《資通安全管理法》及相關子法 | 待評估 |
| **電磁相容** | CNS 相關標準 | 待評估 |

> 台灣市場若涉及進口車或國產車搭載，須由 OEM 或代理商依交通部規定辦理審驗。

## 5. 瑞士／歐盟市場（Switzerland / European Union）

| 類別 | 可能適用之法規／標準 | 現階段狀態 |
| :--- | :--- | :--- |
| **型式認證** | EU Whole Vehicle Type Approval (WVTA) | 待評估 |
| **網路安全** | UNECE R155（Cybersecurity） | 待評估 |
| **軟體更新** | UNECE R156（Software Update） | 待評估 |
| **自動駕駛** | UNECE R157（Automated Lane Keeping Systems, ALKS） | 待評估（視功能等級） |
| **功能安全** | ISO 26262 | 待評估 |
| **GDPR** | 歐盟一般資料保護規則 | 待評估 |

> 瑞士雖非歐盟成員，但通常自願採用 UNECE 法規，實務上須與歐盟市場一併考量。

## 6. 證照取得之前置條件（Checklist）

在正式提出任何證照申請前，本專案預計完成以下內部準備工作：

- [ ] 釐清最終產品功能邊界（輔助 vs. 自動駕駛等級）
- [ ] 完成功能安全（ISO 26262）初步危害分析
- [ ] 完成網路安全（ISO 21434）初步威脅分析
- [ ] 完成數據流向盤點與隱私衝擊評估
- [ ] 確認 OTA 升級架構與合規設計
- [ ] 確認硬體平台（中國旗艦電車）之既有認證狀態
- [ ] 委託當地合格實驗室進行預測試
- [ ] 備妥技術文件與測試報告（依各市場要求）

---

## 7. 現階段立場

**本專案目前為 POC／概念階段**：

- ❌ 尚未取得任何國家之車輛型式審驗
- ❌ 尚未取得任何功能安全／網路安全認證
- ❌ 尚未完成演算法備案或數據安全評估
- ❌ 尚未與任何 OEM 簽署正式量產合約

**未來進入實車部署前，將依實際市場、車型、功能，向各該管主管機關依法申請必要之認證或審驗。**
